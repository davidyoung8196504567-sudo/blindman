FUZZY ART MAP NEURAL NETWORK AUTOMATIC SPEECH RECOGNITION SYSTEM 

IMPORTANT:

1. Ammend your DOS PATH statement to identify the location of your "matlab.exe" file

	eg. path=c:\matlab\bin;

2. Ammend your both your MATLAB and DOS PATH statements to identify the location of your ASR_DEMO directory

	eg. path=c:\asr_demo;

3. The demo can only be run under Windows, Run one of the following commands:

	1. "stdemo.exe voxrecgl.std" - Graphics Learning
	2. "stdemo.exe voxrecgt.std" - Graphics Testing
	3. "stdemo.exe voxrecfl.std" - Fast Learning (no graphics)
	4. "stdemo.exe voxrecft.std" - Fast Testing (no graphics)

4. The ASR system stores the template information in the file "FARTMAPT.MAT".
   To clear all template information, delete or rename this file.
